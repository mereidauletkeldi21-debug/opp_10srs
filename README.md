# Банкомат жүйесі — C++ жобасы

## 1. Жоба туралы

Бұл жоба C++ бағдарламалау тілінде жасалған банкомат жүйесінің оқу үлгісі болып табылады. Бағдарлама клиентті PIN код арқылы тексереді, банк шотындағы балансты көрсетеді, ақша салуға және ақша шешуге мүмкіндік береді. Сонымен қатар орындалған операциялардың тарихын сақтайды.

## 3. Қолданылған технологиялар

- C++17
- Объектіге бағытталған бағдарламалау
- Кластар мен объектілер
- Инкапсуляция
- Мұрагерлік
- Композиция және агрегация

## 4. Бағдарламаның мүмкіндіктері

1. Клиентті PIN код арқылы тексеру.
2. Банк клиенттері туралы ақпаратты көрсету.
3. Шоттағы балансты тексеру.
4. Шотқа ақша салу.
5. Шоттан ақша шешу.
6. Операциялар журналын қарау.
7. Құрылған шоттар мен операциялар санын көрсету.

## 5. Жоба файлдары

- `Client.h` және `Client.cpp` — клиент және оның ішкі `Card` класы.
- `Account.h` және `Account.cpp` — банк шоты, баланс және статикалық шот санағышы.
- `Transaction.h` және `Transaction.cpp` — негізгі операция класы және одан туындайтын `Deposit`, `Withdrawal` кластары.
- `TransactionLog.h` және `TransactionLog.cpp` — операциялар журналын жүргізу.
- `Bank.h` және `Bank.cpp` — клиенттер мен банк шоттарын басқару.
- `ATM.h` және `ATM.cpp` — банкоматтың негізгі әрекеттері.
- `main.cpp` — бағдарламаның негізгі бөлігі.
- `UML.png` — кластар арасындағы байланысты көрсететін диаграмма.

## 6. Объектіге бағытталған бағдарламалау талаптары

1. **Статикалық мүшелер:** `Account` және `Transaction` кластарында статикалық санағыштар мен әдістер бар.
2. **Friend:** `Account` класында `Bank` класына және `printAccountDetails` функциясына арнайы рұқсат берілген.
3. **Ішкі класс:** `Client` класының ішінде `Card` класы орналасқан.
4. **Объектілер массиві:** `Bank` класында `Account` объектілерінің массиві қолданылады.
5. **Композиция:** `ATM` класының құрамында `TransactionLog` объектісі бар.
6. **Агрегация:** `Bank` клиенттермен көрсеткіштер арқылы байланысады. Клиенттер банк объектісінен бөлек құрылады.
7. **Мұрагерлік:** `Deposit` және `Withdrawal` кластары `Transaction` базалық класынан туындайды.
8. **Инкапсуляция:** кластардың деректері `private` бөлімінде сақталып, оларға әдістер арқылы қол жеткізіледі.

## 7. Бағдарламаны құрастыру

Барлық `.cpp` және `.h` файлдарын бір бумаға орналастырыңыз. Терминалда төмендегі команданы орындаңыз:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp Client.cpp Account.cpp Transaction.cpp TransactionLog.cpp Bank.cpp ATM.cpp -o atm
```

Бағдарламаны іске қосу:

```bash
./atm
```

Windows жүйесінде `atm.exe` файлын іске қосыңыз.
